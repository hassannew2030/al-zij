# اختبار المواقيت — سنة كاملة × ١٥ مدينة

- `oracle.py` حساب مرجعي مستقل (خوارزمية PrayTimes اللي Aladhan مبني عليها) بنفس القواعد: تقدير الشفق بنسبة الزاوية، واليوم القطبي على ٦٥°.
- `js.js` بيشغّل حساب الزيج نفسه (من al-zij-v2.html) لكل يوم في السنة.
- `compare.py` بيقارن ويفحص: أكبر فرق، الترتيب، القفزات، الأيام المقدّرة والقطبية.

التشغيل (من فولدر الشغل اللي فيه merge/al-zij-v2.html):
python3 oracle.py cfg.json ref.json && node js.js && python3 compare.py 2

## التوقيت الصيفي
`dst.js` بيحط الجوال في تورونتو وأوسلو ولندن وسانتياجو والرياض، ويحسب أيام قبل وبعد تغيير الساعة، ويتأكد إن الظهر ماشي مع الساعة الصح لكل يوم.
node dst.js
