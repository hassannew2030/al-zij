# جداول أم القرى الرسمية ٢٠٢٦–٢٠٣٠

مواقيت الصلاة والتاريخ الهجري لكل مدن قائمة الموقع الرسمي (١٧٣ مدينة ومحافظة) لكل يوم من ٢٠٢٦ لـ ٢٠٣٠.

- المصدر: `https://umqserv.kacst.gov.sa/api/v1/Prayer/GetPrayerByYear?lang=en&format=24&yg=YYYY&lat=..&lon=..&zone=3`، وهو الـ API اللي موقع ummulqura.org.sa بيعرض منه. نُزّل ١٢ أكتوبر ٢٠٢٦.
- `cities.json`: نسخة من `https://www.ummulqura.org.sa/assets/data/cities.json` (المعرّف والاسم والإحداثيات اللي الموقع بيبعتها للـ API).
- `YYYY.json`: `cities[id][i]` = `"fajr sunrise dhuhr asr maghrib isha"` بتوقيت السعودية لليوم رقم i من ١ يناير، و`hijri[i]` = تاريخ أم القرى لنفس اليوم (واحد لكل المدن).

اتأكد: كل ملف فيه كل أيام السنة لكل مدينة، والمواقيت مترتبة، والعشاء = المغرب + ٩٠ (١٢٠ في رمضان)، والهجري واحد في كل المدن، وجدة ٢٠٢٧ طابقت `tests/prayer/umm-al-qura-official-2027.json` يوم بيوم.

ملاحظة عن الـ API: بيقبل أي إحداثيات وأي `zone` (حتى كسور زي 3.5) ومن غير توقيت صيفي، وبيرجع أرقام حتى في الأماكن القطبية (ترومسو في يونيو) اللي مفيهاش فجر أو شروق حقيقي.
