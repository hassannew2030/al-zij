# fable/ — تصميم الحاسوب للزيج (نسخة Fable)

صفحة واحدة: `fable/index.html`. تُبنى بأمر واحد من جذر المستودع:

```
python3 fable/tools/build.py     # يبني fable/index.html و fable/version.json
python3 fable/tools/verify.py    # يثبت أن كل كتلة منسوخة تطابق beta/index.html@5d74e8f بايتًا ببايت
```

## الملفات

| الملف | المحتوى |
|---|---|
| `index.html` | الصفحة المبنية (ملف واحد مثل beta). لا تُعدَّل باليد. |
| `version.json` | رقم بناء هذه الصفحة؛ الصفحة تقرؤه لتحدّث نفسها. |
| `src/style.css` | التصميم كله، مكتوب من الصفر. |
| `src/shell.html` | هيكل الصفحة الجديد: الشريط الجانبي، شاشة الساعة (المسرح + عمود اليوم)، الصلاة، المزيد، نافذة الأوامر، نافذة الاختصارات. |
| `src/clock-simple.js` | الساعة البسيطة، مرسومة من الصفر. |
| `src/clock-grand.js` | الزيج الكبرى بكل حلقاتها، مرسومة من الصفر. |
| `src/util.js` | أدوات مشتركة للساعتين (كلها تقرأ من كائنات المحرك). |
| `src/app.js` | منطق الواجهة الجديدة: مؤقّت واحد، التكبير، الأوامر، لوحة المفاتيح، التحديث الذاتي. |
| `src/pre.js` | يوقف مؤقّتات الرسم المنسوخة حين تُخفى الصفحة ويعيدها عند ظهورها. |
| `src/bridge.js` | يستبدل `renderer.tick` على النسخة الواحدة (لا على الصنف) ليرسم الساعتين الجديدتين. |
| `src/en.js` | إنجليزية العبارات الجديدة فقط؛ قاموس beta يغلب حيثما وُجدت العبارة. |
| `tools/build.py` · `tools/verify.py` | البناء والتحقق. |
