## لوقو المينا (جوه الساعة)
`dial-mark/dial-mark-options.png` — ٣ شكلات مركّبة على ساعة الزيج تحت الـ١٢:
- أ: نجمة بالإبرة الحمرا + كلمة «الزيج»
- ب: نجمة صغيرة + «الزيج» أكبر
- ج: النجمة بالإبرة لوحدها

## المجلدات
- `sheets/` صفحات المقارنة (كبير + مقاس الأيقونة)
- `svg/` و `png/` كل تصميم لوحده
- `src/` السكريبتات اللي رسمتهم وصور القمر
